# Imágenes Gratuitas para VersaBold WEB PRINCIPAL

**Status:** Guía de descarga de imágenes CC0 (sin restricciones de derechos de autor)

Todas las imágenes recomendadas abajo son **100% gratuitas** y **libres de derechos** para uso comercial.

---

## 📥 Cómo descargar

1. Abre cada URL en tu navegador
2. Busca una imagen que se ajuste al concepto
3. Click derecho → "Guardar imagen como..."
4. Guarda en: `WEB PRINCIPAL/assets/images/` con el nombre exacto indicado

## ✨ BONUS: Herramientas para editar imágenes (gratuitas)

Si necesitas ajustar las imágenes descargadas:

1. **[Canva](https://www.canva.com/)** — Edición online fácil
2. **[Pixlr](https://pixlr.com/)** — Editor online sin registrarse
3. **[ImageMagick](https://imagemagick.org/)** — Terminal (avanzado)
4. **[TinyPNG](https://tinypng.com/)** — Comprimir imágenes

## 📝 Notas importantes

- ✅ Todas las fuentes son **CC0** (Unsplash, Pexels, Pixabay)
- ✅ **No requieren atribución** (pero puedes dar crédito si quieres)
- ✅ **Uso comercial permitido**
- ✅ Descarga en **WebP** si es posible (mejor compresión)
- ⚠️ Si descarga **JPG/PNG**, convierte a WebP con [cwebp](https://developers.google.com/speed/webp/docs/cwebp) o [TinyPNG](https://tinypng.com/)
